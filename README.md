# MatZip (Blender version)
CLI tool that takes in .zip files from ambientCG and turns them into simple .mz files which can be read by the Blender plugin to easily add textures to your objects

## Usage
usage: mz [options] ambientCG_zip output
  options:
    -k, --keep     Does something
    -k filename     
    -c, --command required     Something else
    -d [optlistitem1 optlistitem 2 ... ]     Something with list
